1️⃣ What are Template Literals? Template Literals use backticks (`) instead of single or double quotes. let name = "Kamarudheen"; console.log(`Hello, ${name}!`); Output: Hello, Kamarudheen! 👉 We use `${}` to insert variables or expressions inside a string. 2️⃣ Inserting Variables Template Literals make it easy to combine text and variables. let name = "Kamarudheen"; let role = "Frontend Developer"; console.log(`My name is ${name} and I am a ${role}.`); Output: My name is Kamarudheen and I am a Frontend Developer. 👉 No need to use the `+` operator for string concatenation. 3️⃣ Using Expressions We can also use expressions directly inside `${}`. let a = 10; let b = 20; console.log(`The total is ${a + b}`); Output: The total is 30 👉 Any valid JavaScript expression can be used inside `${}`. 4️⃣ Multi-line Strings Template Literals make it easy to create multi-line strings. let message = `Hello Kamarudheen, Welcome to JavaScript! Keep learning and improving.`; console.log(message); Output: Hello Kamarudheen, Welcome to JavaScript! Keep learning and improving. 👉 We don't need to use `\n` for every new line. 5️⃣ Practical Example let product = "Laptop"; let price = 75000; console.log(`Product: ${product} Price: ₹${price}`); Output: Product: Laptop Price: ₹75000 👉 This is useful when creating dynamic content. 6️⃣ Template Literals vs String Concatenation Traditional way: let name = "Kamarudheen"; console.log("Hello " + name); Using Template Literals: console.log(`Hello ${name}`); ✅ Template Literals are usually cleaner and easier to read. 🧩 Small Practice Challenge Predict the output: let name = "Kamarudheen"; let age = 25; console.log(`My name is ${name} and I will be ${age + 1} next year.`); 🤔 What will be the output?
