1️⃣ What is an Array? An array allows us to store multiple values in a single variable. let fruits = ["Apple", "Banana", "Orange"]; console.log(fruits); Output: ["Apple", "Banana", "Orange"] 👉 Arrays are useful for storing collections of related data. 2️⃣ Accessing Array Elements JavaScript arrays use zero-based indexing. let fruits = ["Apple", "Banana", "Orange"]; console.log(fruits[0]); // Apple console.log(fruits[1]); // Banana 👉 The first element always starts at index 0. 3️⃣ Changing Array Elements We can change an element using its index. let fruits = ["Apple", "Banana", "Orange"]; fruits[1] = "Mango"; console.log(fruits); Output: ["Apple", "Mango", "Orange"] 👉 Arrays are mutable, meaning their elements can be changed. 4️⃣ Array Length The .length property tells us how many elements are in an array. let fruits = ["Apple", "Banana", "Orange"]; console.log(fruits.length); Output: 3 5️⃣ Adding & Removing Elements JavaScript provides several useful methods: 👉 push() → adds to the end 👉 pop() → removes from the end 👉 unshift() → adds to the beginning 👉 shift() → removes from the beginning let fruits = ["Apple", "Banana"]; fruits.push("Orange"); fruits.pop(); console.log(fruits); Output: ["Apple", "Banana"] 6️⃣ Looping Through an Array We can use a for loop to access each element. let fruits = ["Apple", "Banana", "Orange"]; for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); } 👉 Loops allow us to process array elements one by one. 7️⃣ Checking if a Value is an Array We can use Array.isArray(). let fruits = ["Apple", "Banana"]; console.log(Array.isArray(fruits)); Output: true 👉 This helps us check whether a value is an array. 🧩 Small Practice Challenge Predict the output: let numbers = [10, 20, 30]; numbers.push(40); numbers[1] = 25; console.log(numbers); console.log(numbers.length); 🤔 What will be the output?
