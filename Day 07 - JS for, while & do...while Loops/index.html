1️⃣ for Loop Best when you know exactly how many times to repeat something. for (let i = 1; i <= 5; i++) { console.log(i); } Output: 1 2 3 4 5 2️⃣ while Loop Runs as long as a condition stays true. Useful when you don't know the exact number of repetitions in advance. let i = 1; while (i <= 5) { console.log(i); i++; } Output: 1 2 3 4 5 3️⃣ do...while Loop Similar to while, but it runs the code block once first, then checks the condition. This means it always executes at least once, even if the condition is false from the start. let i = 1; do { console.log(i); i++; } while (i < 1); Output: 1 ⚠️ Common JavaScript Gotcha An incorrect or missing update step causes an infinite loop, which can freeze or crash the browser tab. let i = 1; while (i <= 5) { console.log(i); // forgot i++ here — this never stops } 🧩 Small Practice Challenge Predict the output before running this code: let i = 10; do { console.log(i); i++; } while (i < 5); Output : 10
