# 30-days-of-javascript

This repo tracks my daily JavaScript learning journey. Each folder covers one concept with a short explanation and runnable code examples. I also post a recap of each day on [LinkedIn](https://linkedin.com/in/kamarudheen-c-a-4946571ab).
