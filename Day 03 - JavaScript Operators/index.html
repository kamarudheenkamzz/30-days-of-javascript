Simple Explanation : Operators let you do things with your data. There are a few main types: Arithmetic: + - * / % ** Assignment: = += -= *= Comparison: == === != !== Logical: && || ! Common Operators let price = 500; let discount = 50; let finalPrice = price - discount; // Arithmetic let hasDiscount = finalPrice < price; // Comparison let isValid = hasDiscount && true; // Logical console.log(finalPrice); console.log(isValid); Output: 450 true ⚠️ Common JavaScript Gotcha console.log("5" == 5); console.log("5" === 5); Output: true false
