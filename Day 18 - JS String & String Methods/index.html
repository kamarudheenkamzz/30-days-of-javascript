1️⃣ What is a String? A string is a sequence of characters used to represent text. let name = "Kamarudheen"; console.log(name); Output: Kamarudheen 👉 Strings can be written using single quotes, double quotes, or backticks. 2️⃣ String Length The .length property tells us the number of characters in a string. let message = "Hello"; console.log(message.length); Output: 5 👉 String indexing starts from 0, just like arrays. 3️⃣ Accessing Characters We can access individual characters using their index. let word = "JavaScript"; console.log(word[0]); console.log(word[4]); Output: J S 👉 The first character is always at index 0. 4️⃣ Changing Case JavaScript provides methods to change the case of a string. let text = "JavaScript"; console.log(text.toUpperCase()); console.log(text.toLowerCase()); Output: JAVASCRIPT javascript 👉 These methods are useful when comparing or displaying text. 5️⃣ Finding & Checking Text We can use includes() and indexOf() to check whether a string contains specific text. let message = "I am learning JavaScript"; console.log(message.includes("JavaScript")); console.log(message.indexOf("learning")); Output: true 5 👉 includes() returns true or false. 👉 indexOf() returns the position of the text. 6️⃣ Extracting Parts of a String We can use slice() to extract part of a string. let text = "JavaScript"; console.log(text.slice(0, 4)); Output: Java 👉 slice() returns a portion of the original string. 7️⃣ Replacing & Trimming Text Some useful string methods are: 👉 replace() → replaces text 👉 trim() → removes extra spaces 👉 split() → converts a string into an array let text = " Hello World "; console.log(text.trim()); Output: Hello World 👉 These methods are commonly used when processing user input. 🧩 Small Practice Challenge Predict the output: let text = "JavaScript"; console.log(text.length); console.log(text.toUpperCase()); console.log(text.includes("Script")); console.log(text.slice(0, 4)); 🤔 What will be the output?
