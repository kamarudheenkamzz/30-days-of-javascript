2️⃣ Changing Text Content We can use `textContent` to update the text of an HTML element. HTML:

Hello World

JavaScript: let title = document.getElementById("title"); title.textContent = "Welcome Kamarudheen!"; Output: Welcome Kamarudheen! 👉 This changes the text dynamically. 3️⃣ Changing HTML Content We can use `innerHTML` to change the HTML inside an element. HTML:
Hello
JavaScript: document.getElementById("box").innerHTML = "Welcome!"; Output: Welcome! (Bold) 👉 `innerHTML` can insert HTML elements and content. 4️⃣ Adding New Elements We can create and add new HTML elements using JavaScript. HTML:
    JavaScript: let list = document.getElementById("list"); let item = document.createElement("li"); item.textContent = "JavaScript"; list.appendChild(item); Output: • JavaScript 👉 `createElement()` creates an element, while `appendChild()` adds it to the page. 5️⃣ Removing Elements We can also remove HTML elements using JavaScript. HTML:

    Hello World

    JavaScript: let message = document.getElementById("message"); message.remove(); Output: The paragraph is removed. 👉 `remove()` removes an element from the DOM. 6️⃣ Changing CSS Classes We can use `classList` to add or remove CSS classes.
